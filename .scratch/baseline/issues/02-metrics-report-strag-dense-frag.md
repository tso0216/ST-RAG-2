# 02 指標、報表，接上 strag 和 dense_frag

Status: resolved
Blocked by: 01

規則以 `.scratch/baseline/spec.md` 為準，這張做〈指標〉〈報表〉〈命令列〉的 `run` 和 `report`，以及 `strag`、`dense_frag` 兩個系統。

## 要做

研究者可以跑出第一張比較表：主系統對片段 dense，兩列、全部指標。

- 系統的共同介面：輸入一題，輸出答案、取回的片段 id、取回的文章 id、成本、錯誤訊息；`strag` 另外帶每個片段的退讓標記。
- `strag`：規劃器 → 檢索（含兩種退讓）→ 生成器，全部預設參數，用系統原本的生成器提示詞和相關判斷快取。
- `dense_frag`：把現有的片段 dense 函式搬進 baseline，原位置不留，引用和測試跟著搬。生成用三個 dense 系統共用的精簡版提示詞（這張寫）。
- `run --system <名稱> [--k N]`：跑 50 題存結果檔；一題出錯只記那題。生成不快取。
- 六項指標和計分規則，含 95% 信賴區間。
- `report <評審檔…>`：主表和依題型分的表。
- 更新系統 README 裡 `eval/` 的說明和過期的資料量。

## 完成條件

- [x] 主表數字貼在 `## Answer`，連同出錯、地點解析不到、取回為空的題數。
- [x] 指標的單元測試涵蓋：時間不明片段不計分、退讓片段不算違規、比較題的時間條件、失敗題算進分母。
- [x] 片段 dense 原本的位置沒有殘留，`pytest` 全過。
