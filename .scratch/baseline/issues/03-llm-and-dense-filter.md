# 03 llm 和 dense_filter

Status: resolved
Blocked by: 02

規則以 `.scratch/baseline/spec.md` 為準，這張做〈各系統的檢索〉的 `dense_filter` 和〈生成〉的 `llm`。

## 要做

比較表多兩列：不檢索的 LLM，和最強的對照組。

- `llm`：只給問題，Opus 直接回答。沒有取回，檢索指標的格子留空。
- `dense_filter`：
  - 新提示詞：Opus 從問題產生一組或多組過濾條件（地點名、月份、平日／假日、時段），比較題可以多組。
  - 地點對片段的地點名稱做字串比對，不經 Nominatim、不展開區域。
  - 時間用跟主系統相同的比對規則，不明算符合。
  - 沒有 JEV 相關判斷、沒有退讓；過濾後取 cosine top-k，多組各取 top-k 再合併。
  - 生成用 02 寫好的精簡版提示詞。
- 這個系統不能變成主系統的消融：不要呼叫主系統的規劃器、地點解析或退讓。
