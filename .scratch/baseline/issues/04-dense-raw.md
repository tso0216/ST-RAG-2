# 04 補抓原文，dense_raw

Status: ready-for-agent
Blocked by: 02

規則以 `.scratch/baseline/spec.md` 為準，這張做〈各系統的檢索〉的 `dense_raw` 和 `build-chunks`。跟 03 互不相依，可以同時做。

## 要做

比較表補上最後一列：對遊記原文做的一般 RAG。

- 語料是資料庫裡有片段的 248 篇遊記，不多不少。本機的原文封存只有其中 212 篇，缺的 36 篇用現有的 PTT 爬蟲補抓，放在跟其他原文同一個地方。封存裡多出來、資料庫沒有片段的文章不收。
- `build-chunks`：內文加推文，以段落為界，每段約 500 字、重疊 100 字；原文段和 embedding 寫進 baseline 自己的 `chunks.db`。`chunks.db` 不進版控。
- `dense_raw`：原問題對所有原文段的 cosine，取 top-k；取回的文章 id 由原文段所屬的文章得出。生成用 02 的精簡版提示詞。
- 名稱照 spec 叫「原文段」，不要叫片段。

有文章補抓不到（已被刪文等）就停下來：在 `## Comments` 列出抓不到的文章 id，其中哪些是 ptt_v2 的標準文章、影響哪幾題，再回報，由使用者決定怎麼處理。不要自己改語料範圍或題目。
