# 01 評審與校準

Status: resolved
Blocked by: —

規則以 `.scratch/baseline/spec.md` 為準，這張做〈評審〉〈校準〉〈檔案〉裡評審檔的部分，和〈清理〉裡舊測試那一項。舊評測的設計不要參考。

## 要做

研究者拿到一份結果檔（每題的答案），可以用 `judge` 得到每題的評審判斷；也可以用 `calibrate` 在正式跑之前確認評審的問法靠得住。這時還沒有任何系統，結果檔先用手寫的或測試用的。

- baseline 資料夾的骨架和命令列入口。
- 讀 ptt_v2 題目：問題、時間條件、標準片段、標準文章、排除片段與理由、`expect`、比較題的選項。
- 結果檔的格式（spec〈檔案〉），之後四張 ticket 的系統都寫這個格式。
- `judge <結果檔> [--n N]`：覆蓋和無支持兩題 Noul、重問 n 次、分數只取第 1 次、印不一致和一致率、存評審檔。不快取。
- `calibrate [--n N]`：用 ptt_v2 的校準檔驗兩題，印沒過的條目。
- 拿掉出題工具裡依賴舊評審的 `calibrate`；刪掉舊評測留下、已經跑不了的測試。

動手前先確認一件事：無支持那題的 `state` 要放整份答案加所有標準片段，挑標準片段最多的題實際問一次，確認 JEV 吃得下。吃不下就停下來，在 `## Comments` 記下限制再回報。

## Answer

評審在 `src/strag_v3/eval/baseline/judge.py`，校準在 `calibrate.py`，命令列 `python -m strag_v3.eval.baseline judge|calibrate`。

### 校準

第一版問法（「答案有沒有涵蓋這條重點？意思相同就算」）：覆蓋沒過 28 / 452，全部是反向答案沒擋住（反向答案把結論改成相反、或把時間換掉，評審仍判涵蓋）；無支持沒過 1 / 100（stay-10 的正向答案寫「5 月」，問的是 4 月，被判有無支持）。

改了評審提示詞（沒動題目檔和校準檔）：

- 覆蓋：改問「答案有沒有說出跟這條重點相同的事實」，明說結論相反、數字或時間不同、地點不同都算沒涵蓋；重點開頭寫了時間或地點時，答案的也要對得上。
- 無支持：補一句「時間看的是片段自己的時間標籤，不是問的時間：答案明說這是另一個時間的經驗、而且跟片段的時間標籤一致，就算有依據」。
- 另外試過把覆蓋改問成「這條重點說的事成立嗎」，反而多出兩條正向漏判，沒採用。

改後 `calibrate --n 3`：覆蓋沒過 7 / 452，無支持沒過 0 / 100；n=3 的一致率覆蓋 98.9%、無支持 100%（不一致 5 筆）。

| 題型 | 覆蓋 | 無支持 |
|---|---|---|
| 停留經驗 | 2 | 0 |
| 移動經驗 | 3 | 0 |
| 找地點 | 2 | 0 |
| 找時間 | 0 | 0 |
| 比較 | 0 | 0 |
| 合計 | 7 / 452 | 0 / 100 |

沒過的條目（都是反向答案沒擋住；反向答案講同一件事但結論相反，評審仍判涵蓋）：

- stay-02｜expect 4｜夜景能見度只有最低的等級｜noul 0.65
- stay-05｜expect 4｜9 點半重新點燈｜noul 0.62
- move-02｜expect 1｜比賽結束後仍來得及趕上 23:00 左右往上野的末班車｜noul 0.61
- move-07｜expect 1｜颱風影響下，飛福岡的 NH3847 最後有飛｜noul 0.78
- move-09｜expect 3｜散場後巨蛋外面仍擠滿人，只能慢慢離開｜noul 0.69
- place-02｜expect 7｜肥後細川庭園：湖畔另一側是金黃銀杏｜noul 0.88
- place-03｜expect 3｜長池親水公園：用過早餐後富士山頭聚集了許多白雲｜noul 0.78

意思是：覆蓋率對「講到同一件事但說反了」的答案會稍微高估（452 條裡 7 條）。無支持判斷在校準上全對。

### judge --n 3（手寫的結果檔）

5 題：正向答案、反向答案、出錯（answer 為 null）、「沒有找到符合的經驗」、一段常識補答。出錯那題沒送評審；其他 4 題各問 3 次，三次全部一致（一致率覆蓋 100%、無支持 100%），評審檔裡有三次的全部 noul。常識補答判無支持 0.90／0.92／0.90，「沒有找到符合的經驗」判無支持 0.08。再跑一次 `judge` 另存成 `<結果檔>.<時間>.judge.json`，舊檔沒被蓋掉。
