# 07: 答案評估

**What to build:** 用 Claude Opus 5.5 當評審，評估每題答案的兩項指標：

- `expect` 覆蓋率：逐條檢查答案有沒有涵蓋題目的 `expect` 重點。
- 時間誤植率：答案把別的時段的經驗說成問題問的時段的比例。

兩項指標都併入評估框架的彙總結果。生成器和評審用的是同一個模型，這是研究者的決定，要在結果裡註明。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 評估框架可以選擇開啟答案評估；開啟後，結果包含每題和彙總的 `expect` 覆蓋率與時間誤植率
- [ ] 評審的判斷依據逐條留存，方便人工抽查
- [ ] 評審結果有快取，重跑評估時不用重新呼叫
- [ ] 評估 seam 測試用手寫的評審結果，驗證彙總數值算得正確；評審本身不寫測試
