# 08: mock 擴充起草

**What to build:** 照 mock README 的流程，把 mock 擴充到大約 10 個景點、30 題：

- 四種題型都要有：停留、找時間、找地點、比較。
- 每個景點都有正例遊記，也有時空條件避開所有題目的難負例遊記。
- 每題補上 `type`、`split`、`gold_plan`；30 題中 10 題是 dev，20 題是 test。
- 只用 OSM 查得到的地點（見 `docs/adr/0002-osm-place-resolution.md`）：
  - 起草時把每個景點和區域都拿去 Nominatim 確認。
  - 區域要確認解析出來的是行政區，不是車站或公車站；OSM 沒有資料的區域（例如嵐山）換成別的區域。
  - 店名不明的店改成有真實店名的店，或直接拿掉；不用「哲學之道、南禪寺周邊」這種自己取的範圍。
  - 現有 mock 遊記裡不符合的地點也一起改。
- `gold_plan` 的 `space` 照 13 的新格式寫。

起草完跑抽取，交給研究者審稿。`relevant_contents` 留給 09 由研究者確認。
