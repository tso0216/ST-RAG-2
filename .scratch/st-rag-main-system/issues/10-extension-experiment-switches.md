# 10: 延伸實驗設定

**What to build:** 評估框架加上一個可切換的延伸設定，用來跟主實驗對照：

- **few-shot 規劃器**：在規劃器的 prompt 加入少量範例，量化範例到底有沒有幫助。

主實驗維持 zero-shot，這個設定預設關閉。（原本的「LLM 直接輸出時間分布」已隨時間分布一起取消，見 ADR 0001。）

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 評估命令可以開啟這個設定，結果標明有沒有用
- [ ] few-shot 範例不能直接取自 test 題目
- [ ] 能在現有題目上跑完這個設定，並產出結果
