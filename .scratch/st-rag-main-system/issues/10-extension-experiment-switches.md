# 10: 延伸實驗設定

**What to build:** 評估框架加上兩個可切換的延伸設定，用來跟主實驗對照：

- **few-shot 規劃器**：在規劃器的 prompt 加入少量範例，量化範例到底有沒有幫助。
- **LLM 直接輸出時間分布**：問題和片段的時間分布改成由 LLM 直接產生，不經過固定的標籤轉換規則，再跟規則轉換比較。片段的部分要快取，不要每次評估都重新產生。

主實驗維持 zero-shot 和規則轉換，這兩個設定預設關閉。

**Blocked by:** 02, 05

**Status:** ready-for-agent

- [ ] 評估命令可以分別開啟這兩個設定，結果標明用了哪個設定
- [ ] few-shot 範例不能直接取自 test 題目
- [ ] LLM 產生的分布有基本檢查，例如維度要對、非負、加總為 1，不合格就有明確的處理方式；片段的分布有快取
- [ ] 能在現有題目上跑完兩個設定，並產出結果
