# 06: 規劃器正確率

**What to build:** 題目可以附上人工寫的 `gold_plan`。評估時拿規劃器產生的計畫跟它比對，算出規劃器正確率，例如：

- 該留空的欄位有沒有留空
- 地點有沒有解析到同一個 OSM 物件、景點／區域的標記對不對（兩邊的 `space` 都先用地點解析模組解析，不比對名稱字串；見 13）
- 時間標籤是否等價
- `group_by`、`compose` 對不對

有了這個指標，檢索變差時才能分辨問題出在規劃還是比對。

**Blocked by:** 04, 05, 13

**Status:** resolved

- [x] 題目檔支援 `gold_plan` 欄位，格式跟檢索計畫相同
- [x] 評估輸出包含規劃器整體和各欄位的正確率，並依題型分組
- [x] 評估 seam 測試用手寫的計畫，驗證比對規則：寫法不同但意思等價的時間標籤算對，例如 `12` 和 `12-12`；留空和有填算錯；`space` 名稱不同但解析到同一個 OSM 物件算對，種類不同算錯
- [x] 沒有 `gold_plan` 的題目略過這項指標，不會讓評估失敗
