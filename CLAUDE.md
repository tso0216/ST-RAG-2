## Agent skills

### Issue tracker

Issues 以 local markdown 存放在 `.scratch/<feature>/`。See `docs/agents/issue-tracker.md`.

### Triage labels

使用預設五個 triage 角色標籤（needs-triage、needs-info、ready-for-agent、ready-for-human、wontfix），記錄於 issue 檔的 `Status:` 行。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context：根目錄一份 `GLOSSARY.md` + `docs/adr/`。See `docs/agents/domain.md`.
